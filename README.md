# ai-deiven

AI-powered driving learning and education platform.

## Architecture

- **Frontend**: React application for student layout, course progression, assignments, and themes.
- **Backend**: Node.js/Express API with education and assignment management controllers.
- **ML Service**: Python/Flask microservice for intelligent driver assistance and analysis.

## Getting Started

### Prerequisites
- Node.js & npm
- Python 3.x

### Setup & Run
1. **Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

2. **Backend**:
   ```bash
   cd backend
   npm install
   npm start
   ```

3. **ML Service**:
   ```bash
   cd ml-service
   pip install -r requirements.txt
   python app.py
   ```
